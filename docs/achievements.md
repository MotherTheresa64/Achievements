# GitHub Achievement Reference

This document tracks GitHub profile achievements as a learning reference. GitHub's achievement system is a public preview and can change; where GitHub does not publish exact numerical tiers, the values below are treated as community-observed rather than as a stable API contract.

## Currently earnable

| Achievement | Broad trigger | Collaboration required? | Notes |
| --- | --- | --- | --- |
| Quickdraw | Close an issue or pull request within five minutes of opening it | No | Best exercised with a legitimate duplicate, withdrawn proposal, or short-lived test item in a repository you control. |
| Pull Shark | Open pull requests that are merged | No | Community-observed tiers: 2, 16, 128, and 1024 merged PRs. |
| YOLO | Merge a pull request without a code review | No | Non-tiered. This should not be treated as a recommended production practice. |
| Pair Extraordinaire | Co-author commits that land through merged pull requests | Yes | Requires a real GitHub-linked co-author. Community-observed tiers: 1, 10, 24, and 48. |
| Galaxy Brain | Provide answers in GitHub Discussions that are accepted | Yes | Requires another participant to accept the answer. GitHub disabled achievement earning in the official GitHub Community because of coordinated badge-farming, but the feature can still apply in other eligible public-repository discussions. Community-observed tiers: 2, 8, 16, and 32 accepted answers. |
| Starstruck | Create a repository that receives stars | Yes, indirectly | Stars should come from independent users. Published milestones are 16, 128, 512, and 4096 stars. |
| Public Sponsor | Sponsor an open-source contributor through GitHub Sponsors | No collaborator needed | Requires an actual GitHub Sponsors sponsorship. |

## Historical or currently unavailable

- **Arctic Code Vault Contributor** — historical recognition tied to the 2020 GitHub Archive Program; it cannot be newly earned through present-day repository activity.
- **Mars 2020 Helicopter Contributor** — historical recognition tied to qualifying repositories used by the Mars 2020 Ingenuity mission.
- **Heart On Your Sleeve** — experimental achievement that GitHub staff said was re-enabled temporarily by mistake and removed again in 2026.
- **Open Sourcerer** — experimental achievement that GitHub staff said was re-enabled temporarily by mistake and removed again in 2026.

## Evidence policy for this repository

The repository distinguishes between three kinds of claims:

1. **Official** — directly described by GitHub documentation, GitHub product fragments, or GitHub staff.
2. **Community-observed** — repeatedly reproduced by users but not guaranteed by GitHub as a stable contract.
3. **Historical** — tied to a past event or program and not currently earnable.

The project should never create fake collaborators, fake stars, fabricated reviews, or misleading claims of outside contribution. The useful signal is the engineering work and transparent workflow; achievements are secondary profile markers.
